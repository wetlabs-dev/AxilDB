# Fonts

AxilDB bundles IBM Plex Mono for plant label rendering.

- `IBMPlexMono-Regular-Latin1.woff2` is used by browser label previews.
- `IBMPlexMono-Regular.ttf` is used by server-generated PDF labels.
- `IBMPlexMono-LICENSE.txt` contains the SIL Open Font License 1.1.

The font files are included unmodified and are used only as bundled/embedded application assets.

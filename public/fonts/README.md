# Fonts

AxilDB bundles local font files so the app renders consistently without depending on remote font services.

- `Fraunces-*.ttf` is used for headings and botanical display text.
- `Inter-*.ttf` is used for body text and UI controls.
- `IBMPlexMono-Regular-Latin1.woff2` is used by browser label previews for plant IDs.
- `IBMPlexMono-Regular.ttf` is used by server-generated PDF labels for plant IDs.

Licenses:

- `Fraunces-LICENSE.txt` contains the SIL Open Font License 1.1 for Fraunces.
- `Inter-LICENSE.txt` contains the SIL Open Font License 1.1 for Inter.
- `IBMPlexMono-LICENSE.txt` contains the SIL Open Font License 1.1 for IBM Plex Mono.

The font files are included unmodified and are used only as bundled/embedded application assets.
